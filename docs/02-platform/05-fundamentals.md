# 第 9 周：基本面与估值

> **一句话总结**：基本面回答“这是不是一门好生意”（增长、利润率、现金流、负债），估值回答“现在这个价格贵不贵”（PE、PS、EV/EBITDA、自由现金流收益率）；**好公司 ≠ 好股票**，买得太贵，好公司也可能让你多年不赚钱。

## 1. 和A股对比

| 方面 | A股常见做法 | 美股常见做法 |
|---|---|---|
| 最常用估值 | 市盈率（PE）、市净率（PB） | PE（尤其是**预期 PE**）、PS、EV/EBITDA、自由现金流收益率 |
| 盈利口径 | 扣非净利润 | GAAP 与 **Non-GAAP** 并存（见 [读懂财报](04-reading-filings.md)） |
| 关注重点 | 业绩增速、政策、题材 | **自由现金流**、利润率趋势、**资本回报**（回购和分红） |
| 股东回报 | 分红为主，回购较少 | **回购为主**，很多大公司回购金额是分红的几倍 |
| 估值高低 | 创业板、科创板常有高 PE | 科技巨头 PE 25–40 很常见；市场整体（标普500）预期 PE 长期在 15–23 之间波动 |
| 亏损公司 | ST 风险 | 大量成长公司长期亏损但市值很高，用 PS 或 EV/Sales 估值 |
| 数据获取 | 同花顺 F10 | Yahoo Finance、stockanalysis.com、券商的基本面页面 |

**A股的“扣非净利润”和美股的 Non-GAAP 很像**：都是想剔除一次性因素，但美股的 Non-GAAP 由公司自己定义，剔除的东西更多（尤其是股权激励），要更警惕。

## 2. 三张报表如何连在一起

用一家虚构的咖啡连锁店 **BeanCo** 演示一年的经营，数字单位：百万美元。

### 2.1 利润表：一年赚了多少（权责发生制）

| 项目 | 金额 | 说明 |
|---|---|---|
| 收入 | 1,000 | 卖咖啡 |
| 营业成本 | −400 | 咖啡豆、牛奶、门店员工 |
| **毛利** | **600** | 毛利率 60% |
| 销售及管理费用 | −300 | 总部、广告、租金 |
| 折旧摊销（D&A） | −100 | 咖啡机、装修的“分期费用” |
| **营业利润（EBIT）** | **200** | 营业利润率 20% |
| 利息费用 | −20 | 借款 400，利率 5% |
| 税前利润 | 180 | |
| 所得税（21%） | −38 | |
| **净利润** | **142** | 净利率 14.2% |

### 2.2 现金流量表：一年实际进出了多少现金

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 142 | 从利润表来 |
| + 折旧摊销 | +100 | 非现金费用，加回 |
| − 存货、应收增加 | −20 | 钱压在了库存里 |
| **经营现金流（OCF）** | **222** | |
| − 资本开支（开新店、买咖啡机） | −150 | |
| **自由现金流（FCF）** | **72** | |
| − 分红 | −30 | |
| − 回购 | −20 | |
| 现金净增加 | +22 | |

### 2.3 资产负债表：年末家底

| 资产 | | 负债和权益 | |
|---|---|---|---|
| 现金 | 122（年初 100 + 22） | 借款 | 400 |
| 存货 | 80 | 应付账款 | 100 |
| 门店设备（净值） | 900 | **股东权益** | 602 |
| **合计** | **1,102** | **合计** | **1,102** |

### 2.4 连接关系（记住这三条）

1. **利润表的净利润** → 是现金流量表的**起点**，也会增加资产负债表的**股东权益**（扣掉分红和回购后）。
2. **现金流量表的现金净增加** → 等于资产负债表上**现金**的变化。
3. **资本开支**不进利润表，而是变成资产负债表上的**设备**，之后每年通过**折旧**慢慢进入利润表。

!!! tip "为什么美国投资者特别看重自由现金流"
    BeanCo 净利润 142，但自由现金流只有 72，因为它在快速开新店。如果一家公司**多年净利润很高、自由现金流却一直很低甚至为负**，要问：钱去哪了？是在扩张（可以接受），还是利润质量有问题（应收账款越来越多，可能是收不回来的钱）？

## 3. 八个基本面指标

下面每个指标都给出公式、苹果 FY2024 的计算（数字来自 [读懂财报](04-reading-filings.md) 第 4 节，单位十亿美元）以及判断参考。

### 3.1 收入增长率（Revenue Growth）

\[
\text{收入增长率} = \frac{\text{本期收入}}{\text{去年同期收入}} - 1
\]

苹果：391.0 / 383.3 − 1 = **+2.0%**。对一家 3 万亿市值的公司来说偏慢，所以市场盯着服务收入（增速约 13%）。

| 年增速 | 一般看法 |
|---|---|
| < 3% | 成熟 / 停滞 |
| 5–15% | 稳健增长 |
| 20%+ | 高增长 |
| 50%+ | 超高增长，通常估值也极高 |

### 3.2 毛利率（Gross Margin）

苹果：180.7 / 391.0 = **46.2%**。毛利率反映**定价权**。软件公司 70–90%，苹果 46%，超市（好市多）约 12–13%，汽车 15–25%。**看趋势比看绝对值重要**：毛利率连续下滑，通常说明竞争加剧或成本失控。

### 3.3 营业利润率（Operating Margin）

苹果：123.2 / 391.0 = **31.5%**。在毛利率基础上扣除研发、销售管理费用，反映**整体经营效率**。

### 3.4 自由现金流与自由现金流率（FCF / FCF Margin）

\[
\text{FCF} = \text{经营现金流} - \text{资本开支} \qquad \text{FCF 率} = \frac{\text{FCF}}{\text{收入}}
\]

苹果：FCF = 118.3 − 9.4 = 108.9；FCF 率 = 108.9 / 391.0 = **27.9%**。超过 20% 属于非常优秀。

### 3.5 净资产收益率（ROE）与投入资本回报率（ROIC）

\[
\text{ROE} = \frac{\text{净利润}}{\text{股东权益}}
\]

苹果：93.7 / 57.0 ≈ **164%**。这个数字被大规模回购“放大”了（回购减少了分母），不能和别的公司直接比。更好的指标是 **ROIC**（投入资本回报率），它把债务也算作投入的资本：

\[
\text{ROIC} \approx \frac{\text{营业利润} \times (1 - \text{税率})}{\text{股东权益} + \text{有息负债} - \text{现金}}
\]

ROIC 长期高于 15% 通常说明公司有“护城河”。BeanCo：200 × (1 − 21%) / (602 + 400 − 122) = 158 / 880 ≈ **18%**。

### 3.6 负债水平：净负债 / EBITDA

\[
\text{EBITDA} = \text{营业利润} + \text{折旧摊销} \qquad \text{净负债} = \text{有息负债} - \text{现金及投资}
\]

| 净负债 / EBITDA | 一般看法 |
|---|---|
| < 0（净现金） | 非常稳健（苹果） |
| 0–2 | 健康 |
| 2–4 | 偏高，看行业（公用事业、电信常在这个区间） |
| > 4 | 高杠杆，利率上升时风险大 |

BeanCo：EBITDA = 200 + 100 = 300；净负债 = 400 − 122 = 278；比值 **0.93**，健康。

### 3.7 利息覆盖倍数（Interest Coverage）

\[
\text{利息覆盖} = \frac{\text{EBIT}}{\text{利息费用}}
\]

BeanCo：200 / 20 = **10 倍**。低于 3 倍要警惕。

### 3.8 总股数变化（Share Count）

看**稀释后股数**过去 5 年的变化：

- 苹果：约 165 亿股（2020 财年稀释后，按拆股后口径）→ 约 154 亿股（2024 财年），**每年减少约 2–3%**，每股价值在增加。
- 很多成长科技公司：股数每年**增加** 2–5%（股权激励），你的持股在被稀释。

**每股收益增长 ≈ 净利润增长 + 股数减少的速度**。苹果净利润（剔除一次性税费）增长约 7%，加上股数减少约 2.5%，调整后 EPS 增长约 9–10%。

## 4. 估值指标

### 4.1 市值与企业价值（Market Cap vs Enterprise Value）

\[
\text{市值} = \text{股价} \times \text{总股数}
\]

\[
\text{企业价值 EV} = \text{市值} + \text{有息负债} - \text{现金及投资}
\]

**为什么要 EV**：想象你要买下整家公司。除了付给股东的钱（市值），你还要承担它的债务，但可以拿到它账上的现金。

**例子**：两家公司市值都是 100 亿美元

| | A 公司 | B 公司 |
|---|---|---|
| 市值 | 100 | 100 |
| 有息负债 | 0 | 60 |
| 现金 | 30 | 5 |
| **EV** | **70** | **155** |
| EBITDA | 10 | 10 |
| **EV/EBITDA** | **7.0** | **15.5** |

看 PE 可能差不多，看 EV 才发现 B 贵了一倍还多。

### 4.2 市盈率 PE（Price / Earnings）

\[
\text{PE} = \frac{\text{股价}}{\text{每股收益}} = \frac{\text{市值}}{\text{净利润}}
\]

三种口径，财经网站上都会出现：

| 口径 | 英文 | 用的 EPS | 说明 |
|---|---|---|---|
| 静态 | PE (FY) | 上一个完整财年 | |
| 滚动 | **PE (TTM)** | 过去 12 个月（最近 4 个季度） | Yahoo 上的 “PE Ratio (TTM)” |
| 预期 | **Forward PE** | 分析师预测的未来 12 个月或下一财年 | **美股讨论估值最常用** |

**苹果例子**（假设股价 230 美元，**仅为计算演示**）：

- 用 FY2024 GAAP EPS 6.08：PE = 230 / 6.08 = **37.8**
- 剔除一次性税费后 EPS 约 6.74：PE = 230 / 6.74 = **34.1**
- 若分析师预期下一财年 EPS 7.50：Forward PE = 230 / 7.50 = **30.7**

同一时刻、同一家公司，PE 可以是 31 也可以是 38，所以**讨论 PE 必须说清楚口径**。

**PE 的直观理解**：PE 30 = 盈利收益率（Earnings Yield）1/30 = 3.3%。如果利润不增长，你要 30 年才能“回本”。所以高 PE 必须由**未来增长**来支撑。

### 4.3 PEG

\[
\text{PEG} = \frac{\text{PE}}{\text{未来几年 EPS 年增长率（\%）}}
\]

苹果：Forward PE 30.7，预期 EPS 年增速 10% → PEG ≈ **3.1**。某成长股：Forward PE 40，增速 35% → PEG ≈ **1.1**。经典说法是 PEG ≈ 1 比较合理，但它非常依赖增长预测，只能作参考。

### 4.4 市销率 PS（Price / Sales）

\[
\text{PS} = \frac{\text{市值}}{\text{收入}}
\]

苹果：市值 230 × 154 亿股 ≈ 35,400 亿美元；PS = 3,542 / 391 ≈ **9.1**。

**用途**：给**还没盈利**的成长公司估值。但收入不等于利润：PS 9 的苹果（净利率 24%）和 PS 9 的一家净利率 −10% 的公司完全不是一回事。

### 4.5 EV/EBITDA

苹果 FY2024：EBITDA ≈ 营业利润 123.2 + 折旧摊销 11.4 = 134.6；EV ≈ 3,542 − 50（净现金）≈ 3,492；EV/EBITDA ≈ **25.9**。

优点：不受资本结构（借多借少）和税率影响，适合**同行业公司之间对比**，并购时也常用。

### 4.6 自由现金流收益率（FCF Yield）

\[
\text{FCF Yield} = \frac{\text{FCF}}{\text{市值}}
\]

苹果：108.9 / 3,542 ≈ **3.1%**。可以和**美国 10 年期国债收益率**比较：如果国债给 4% 以上，一只 FCF Yield 3% 的股票，意味着市场预期它的现金流会持续增长。

### 4.7 股息率（Dividend Yield）与总股东回报率

苹果每股年分红约 1.00 美元，股息率 = 1.00 / 230 ≈ **0.43%**，看起来很低。但加上回购（约 950 亿美元 / 3.54 万亿 ≈ 2.7%），**总股东回报率（Shareholder Yield）约 3.1%**。在美股，只看股息率会低估回购型公司。

!!! info "对法国居民的税务提醒"
    美股股息先被美国预扣 15%（签了 W-8BEN 的情况下），再在法国按 PFU 计税并抵扣（详见 [法国居民税务](../01-foundations/04-tax-france.md)）。回购不产生股息，只有你卖出时才在法国就资本利得纳税。所以从税务角度看，**回购对长期持有者更友好**。

### 4.8 市净率 PB（Price / Book）

\[
\text{PB} = \frac{\text{市值}}{\text{股东权益}}
\]

在美股主要用于**银行、保险**等资产负债表就是“生意本身”的公司。苹果 PB 约 62，没有意义（股东权益被回购压小了）。

## 5. 估值的算术：为什么“好公司”也会让你不赚钱

### 5.1 股价收益的拆解

长期来看：

\[
\text{股价收益} \approx \text{EPS 增长} + \text{PE 变化}
\]

再加上股息，就是总收益。

### 5.2 例子：同一家好公司，三种买入价

公司 X 未来 5 年 EPS 每年稳定增长 **12%**（这是一家很好的公司），当前 EPS 5 美元，5 年后 EPS = 5 × 1.12⁵ ≈ **8.81**。5 年后市场给它的 PE 回到行业平均 **22**，股价 = 8.81 × 22 ≈ **194**。

| 买入时 PE | 买入价 | 5 年后股价 | 5 年总收益 | 年化 |
|---|---|---|---|---|
| 15（便宜） | 75 | 194 | +159% | **+20.9%** |
| 22（合理） | 110 | 194 | +76% | **+12.0%** |
| 45（很贵） | 225 | 194 | −14% | **−2.9%** |

**同样的好公司，买在 45 倍 PE，5 年后还亏钱**。2000 年的思科、微软就是这样的真实例子：公司业绩持续增长，但股价十几年没回到 2000 年的高点。

### 5.3 反过来用：当前股价“隐含”了多少增长

如果一只股票 Forward PE 50，你假设 5 年后合理 PE 是 25，想要每年 10% 的回报：

\[
\text{5 年后股价} = \text{现价} \times 1.10^5 = 1.61 \times \text{现价}
\]

\[
\text{需要的 EPS 增长倍数} = 1.61 \times \frac{50}{25} = 3.22 \Rightarrow \text{年增长} \approx 26\%
\]

问自己：这家公司**连续 5 年每年 EPS 增长 26%** 的可能性有多大？这比单纯说“PE 50 太贵了”更有用。

## 6. 不同行业的估值习惯

下面是**粗略的参考区间**，会随利率和市场情绪变化，只用来建立直觉：

| 行业 | 常用指标 | 典型区间（大致） | 例子 |
|---|---|---|---|
| 大型科技 / 软件 | Forward PE、EV/Sales、FCF Yield | PE 25–40 | MSFT、AAPL |
| 半导体（周期性） | Forward PE、EV/EBITDA | PE 波动极大 | NVDA、AMD |
| 消费必需品 | PE、股息率 | PE 18–25，股息 2.5–3.5% | KO、PG |
| 银行 | PB、ROE | PB 1–2 | JPM |
| 能源 | EV/EBITDA、FCF Yield | EV/EBITDA 4–7 | XOM |
| 公用事业 | PE、股息率、净负债/EBITDA | PE 15–20，股息 3–4% | NEE |
| 亏损成长股 | EV/Sales | 差异巨大 | |

!!! warning "周期股的 PE 陷阱"
    钢铁、航运、半导体、能源这类周期股，在**盈利顶峰时 PE 最低**（看起来最便宜），在**盈利谷底时 PE 最高甚至为负**（看起来最贵）。A股你可能见过“低 PE 买入钢铁股，结果下一年利润腰斩”。对周期股要看**周期平均利润**，而不是当年利润。

## 8. 常见坑

1. **只看 PE 不看口径**：TTM、Forward、GAAP、Non-GAAP 混着比。
2. **跨行业比 PE**：银行 PE 10 和软件 PE 30 不能直接比。
3. **低 PE 价值陷阱**：低 PE 往往有原因（行业衰退、利润即将下滑）。
4. **周期股在顶峰时买入“便宜”PE**（第 6 节）。
5. **被 ROE 骗**：大量回购或高杠杆都能把 ROE 推高。看 ROIC 和负债。
6. **忽略股权激励**：Non-GAAP 利润好看，股数却每年增加 3%。
7. **只看一年数据**：至少看 3–5 年趋势。
8. **算得越精确越安心**：估值是区间，不是一个数。所有假设（增长率、未来 PE）都可能错，**留出安全边际**。

### 计算题

1. 某公司市值 500 亿，有息负债 150 亿，现金 50 亿，EBITDA 80 亿。EV/EBITDA 是多少？
2. Forward PE 25，EPS 年增长 8%，5 年后 PE 回到 18。不算股息，年化收益约多少？
3. 公司净利润增长 6%，稀释股数每年减少 3%。EPS 大约增长多少？

??? success "答案"
    1. EV = 500 + 150 − 50 = 600；600 / 80 = **7.5**。
    2. 5 年后股价 / 现价 = 1.08⁵ × 18/25 = 1.469 × 0.72 = 1.058，5 年 +5.8%，年化约 **+1.1%**。
    3. EPS = 1.06 / 0.97 − 1 ≈ **+9.3%**。
