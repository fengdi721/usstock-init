# 第 5 周：券商平台上手（IBKR）与模拟盘

> **一句话总结**：先在 IBKR 的模拟盘（Paper Trading）里把界面、行情、自选股、下单、看持仓这一整套流程练熟，再用真钱；模拟盘不要钱、可以重置，是你本阶段最重要的练习场。

!!! note "本周时间安排（共 5 小时 + 1 小时英语）"
    | 时长 | 内容 |
    |---|---|
    | 1 小时 | 读本文第 1–3 节，弄清 IBKR 有哪几个“入口”、账户结构 |
    | 1 小时 | 开通模拟盘，装好 IBKR Desktop / 手机 App，按第 4 节改成中文 + 设置好布局 |
    | 1.5 小时 | 按第 5 节建 3 个自选股列表，看懂报价窗口每一个字段 |
    | 1.5 小时 | 按第 6 节在模拟盘下 5 笔订单，看懂持仓和账户页面 |
    | 1 小时（英语） | 背第 9 节的界面英文词，能不查字典看懂下单窗口 |

## 1. 和A股对比：你已经会的 vs 需要重新学的

在A股，你用的是同花顺、东方财富或者券商自己的 App。登录、看行情、点“买入”、输入价格和数量（必须是 100 股的整数倍）、确认，就结束了。美股券商的逻辑一样，但有几处明显不同：

| 方面 | A股（同花顺 / 券商 App） | 美股（IBKR） |
|---|---|---|
| 账户 | 一个证券账户，人民币 | 一个账户里可以有多种货币（EUR、USD…），**要自己换汇** |
| 交易单位 | 100 股一手 | 1 股起，还可以买**碎股**（例如 0.3 股） |
| 订单类型 | 基本只有限价单和市价单 | 十几种：限价、市价、止损、止损限价、追踪止损… |
| 有效期 | 当日有效 | DAY（当日）、GTC（撤销前一直有效）等，下周详讲 |
| 交易时间 | 9:30–11:30, 13:00–15:00（北京时间） | 常规 15:30–22:00（巴黎时间），另有盘前盘后 |
| 行情 | 免费 Level-1，Level-2 要付费 | 基础实时行情有免费方案，完整行情要订阅（见第 7 节） |
| 软件数量 | 一个 App | **好几个入口**：网页版、桌面版、手机版、老牌专业版 TWS |
| 模拟盘 | 很少有，或者是第三方模拟炒股 | **官方模拟盘**，和真实账户几乎完全一样的界面和规则 |
| 涨跌颜色 | 红涨绿跌 | **绿涨红跌**（可以改，但建议适应） |

!!! warning "颜色是最容易踩的第一个坑"
    美股所有平台默认 **绿色 = 涨，红色 = 跌**，和A股正好相反。前几周你看到一片红会本能地以为“大涨”。建议**不要**把颜色改回A股习惯，因为以后看英文新闻、TradingView、财经网站全是绿涨红跌，越早适应越好。

## 2. 为什么本路线用 IBKR 做示范

阶段一的 [法国居民账户体系](../01-foundations/03-accounts-france.md) 已经比较过券商。这里只强调和本阶段有关的几点：

1. **期权**：你阶段三要交易期权，IBKR 是欧洲散户能用的期权支持最完整的券商之一。
2. **模拟盘**：IBKR 的模拟盘和真实账户用同一套软件，练熟了直接平移。
3. **换汇便宜**：IBKR 换汇是接近银行间汇率的价格（下下周详讲），对欧元投资者很重要。
4. **法国客户由 Interactive Brokers Ireland（IBIE）服务**，受爱尔兰央行监管，账户里的证券受欧盟投资者赔偿机制保护。

> 如果你最终选的是 Fortuneo CTO 或别的券商，本周内容依然适用：每个平台的“报价、自选、下单、持仓、账户”五块结构是一样的，只是按钮位置不同。

## 3. IBKR 的几个“入口”，先分清楚

很多人第一次用 IBKR 会被搞晕，因为它有好几个软件，功能有重叠。记住下面这张表就够了：

| 入口 | 英文名 | 适合做什么 | 建议 |
|---|---|---|---|
| 网页客户端 | **Client Portal**（也叫 Portal） | 开户、入金、换汇、看报表、改设置、签税表 | **账户管理都在这里做** |
| 新桌面版 | **IBKR Desktop** | 看行情、下单、自选股，界面现代 | **本路线默认用它下单** |
| 手机 App | **IBKR Mobile** | 随时看行情、简单下单、收提醒 | 装上，作为辅助 |
| 专业桌面版 | **TWS**（Trader Workstation） | 功能最全：复杂期权、组合单、风险分析 | 阶段三做期权时再学 |
| 简化 App | IBKR GlobalTrader | 极简下单 | 不推荐，功能太少 |

一个简单的分工原则：**钱和账户的事去 Client Portal，交易的事去 IBKR Desktop / 手机**。

### 3.1 账户结构：真实账户与模拟账户

开户成功后，你其实有两个账户：

```
你的 IBKR 用户
├── 真实账户  U1234567   ← 用真钱，账号以 U 开头
└── 模拟账户  DU1234567  ← 虚拟资金，账号以 DU 开头（D = Demo）
```

- 模拟账户有**单独的用户名**（在 Client Portal 里开通时生成），登录时用这个用户名就进入模拟盘。
- 模拟账户默认给约 **100 万美元**虚拟资金。**建议你改成和真实计划一样的金额**（例如 8,000 美元），否则练出来的仓位感完全不真实。
- 模拟盘可以**重置**（Reset），把资金和持仓恢复初始状态。

!!! tip "怎么判断自己现在在哪个账户"
    IBKR Desktop 和 TWS 在模拟盘下，窗口标题或角落会显示 **Paper Trading**，或者有红色/橙色的醒目标识，账号以 **DU** 开头。下单前养成看一眼账号的习惯。

## 4. 动手：开通模拟盘并装好软件

### 4.1 开通模拟盘（真实账户已批准后）

1. 登录 **Client Portal**（网址 `ibkr.com` → Log In → Client Portal）。
2. 右上角头像 → **Settings（设置）** → 找到 **Paper Trading Account（模拟交易账户）**。
3. 点 **Configure / Request**，确认后会给你一个模拟盘用户名，密码自己设。
4. 在同一页可以选择是否**共享真实账户的行情订阅**（Share real-time market data）。选“是”，模拟盘才有实时行情。

> 如果真实账户还没批下来：IBKR 官网也提供免注册的“试用账户（Free Trial）”，可以先熟悉界面，但功能和数据有限，正式练习还是用开户后的模拟盘。

### 4.2 改成中文界面

IBKR Desktop 和手机 App 都支持简体中文：

- **IBKR Desktop**：右上角齿轮 → Settings → Language → 简体中文。
- **手机 App**：More（更多）→ Settings → Language。

!!! tip "中文还是英文？"
    建议**前两周用中文**，降低学习负担；**第 7 周起切回英文**。因为期权、财报、新闻全是英文，平台英文是最好的“每日词汇课”。第 9 节的词表就是为切换准备的。

### 4.3 推荐的初始布局

IBKR Desktop 打开后，建议整理成 4 块（拖动面板即可）：

```
┌────────────────────┬──────────────────────────┐
│  自选股列表          │   图表（K线）              │
│  Watchlist         │   Chart                  │
│                    │                          │
├────────────────────┼──────────────────────────┤
│  下单窗口            │   持仓 / 订单             │
│  Order Entry       │   Portfolio / Orders     │
└────────────────────┴──────────────────────────┘
```

这个布局和你在同花顺里“左边自选、右边K线、下面下单”的习惯几乎一样，上手最快。

## 5. 读懂报价：一只股票的“盘口”

在自选股里点开一只股票（比如苹果，代码 **AAPL**），你会看到类似下面的报价信息（数字为示例）：

| 字段（英文） | 中文 | 示例 | 含义 |
|---|---|---|---|
| Last | 最新价 | 228.50 | 最近一笔成交价 |
| Change / Chg % | 涨跌 / 涨跌幅 | +1.85 / +0.82% | 相对**前一交易日收盘价** |
| Bid | 买一价 | 228.49 | 当前最高的买单价格 |
| Ask | 卖一价 | 228.51 | 当前最低的卖单价格 |
| Bid Size / Ask Size | 买一量 / 卖一量 | 300 / 500 | 注意：部分平台显示单位是“百股” |
| Spread | 买卖价差 | 0.02 | Ask − Bid，越小流动性越好 |
| Volume | 成交量 | 42.3M | 当天成交股数，M = 百万 |
| Open / High / Low | 开 / 高 / 低 | 227.10 / 229.30 / 226.80 | 当日常规时段 |
| Prev Close / Close | 昨收 | 226.65 | 前一交易日常规时段收盘价 |
| 52W High / Low | 52 周最高 / 最低 | 260.10 / 169.21 | 过去一年的区间 |
| Market Cap | 市值 | 3.45T | T = 万亿美元 |
| P/E | 市盈率 | 34.5 | 第 9 周详讲 |
| Avg Volume | 平均成交量 | 55M | 用来判断今天是否放量 |

### 5.1 和A股盘口的对应

A股你习惯看“五档盘口”：买一到买五、卖一到卖五。美股的 **Bid / Ask** 就是买一 / 卖一。想看更多档位，在 IBKR 叫 **Market Depth / BookTrader（深度行情）**，需要额外行情订阅，长期投资者基本用不上。

### 5.2 计算练习：价差有多贵

假设你要买 50 股，用市价单（以卖一价成交）：

- 苹果（大盘股）：Bid 228.49 / Ask 228.51，价差 0.02 美元。立刻买入再立刻卖出，损失 50 × 0.02 = **1 美元**，约占交易额 11,425 美元的 **0.009%**。
- 某小盘股：Bid 12.40 / Ask 12.60，价差 0.20 美元。50 股损失 50 × 0.20 = **10 美元**，占交易额 630 美元的 **1.6%**。

结论：**同样是“一买一卖”，小盘股的隐性成本可能是大盘股的上百倍**。A股因为有一手 100 股和较密集的挂单，这个问题不明显；美股小盘股、期权上这个成本非常重要，下周的限价单就是用来解决它的。

### 5.3 盘前盘后的报价

美股在常规时段（巴黎时间 15:30–22:00）之外还有：

| 时段 | 美东时间 | 巴黎时间（大多数时候） | 特点 |
|---|---|---|---|
| 盘前 Pre-market | 4:00–9:30 | 10:00–15:30 | 成交稀少、价差大，财报后的第一反应在这里 |
| 常规 Regular | 9:30–16:00 | 15:30–22:00 | 主要流动性 |
| 盘后 After-hours | 16:00–20:00 | 22:00–02:00 | 大部分公司在这时发财报 |

IBKR 的报价窗口会在盘前盘后显示扩展时段价格，有时用灰色或小字标注 **Pre** / **Post**。看到“盘后 −8%”，通常意味着财报不及预期，第二天开盘大概率低开。

!!! info "夏令时错位"
    美国和欧洲切换夏令时的日期不同：每年 3 月中下旬约 2–3 周、10 月底到 11 月初约 1 周，美股会在巴黎时间 **14:30** 开盘、**21:00** 收盘。这几周记得把闹钟提前一小时。

---

!!! danger "欧盟散户买不了 SPY、QQQ、VOO 这类美国 ETF"
    欧盟的 **PRIIPs 法规**要求面向散户的基金提供欧盟格式的关键信息文件（KID），美国注册的 ETF 基本都没有。所以你在 IBKR 爱尔兰作为散户，**下单 SPY、QQQ、VOO、VTI 会被拒绝**（模拟盘一般也会照样拦截）。注意几点：

    - **看行情、看图表不受影响**，SPY、QQQ 依然是你判断大盘的“温度计”。
    - **SPY、QQQ 的期权不受这个限制**，阶段三会用到。
    - 想买美国指数，用欧洲上市的 **UCITS 版本**：

    | 想跟踪 | 美国 ETF（买不了） | UCITS 替代（能买） | 交易所 / 币种举例 |
    |---|---|---|---|
    | 标普500 | SPY / VOO / IVV | **CSPX**（iShares）、**VUAA**（Vanguard，累积型） | 伦敦 LSE，美元 |
    | 纳斯达克100 | QQQ | **CNDX**（iShares）、**EQQQ**（Invesco） | 伦敦 LSE，美元 / 英镑 |
    | 全球发达市场 | URTH | **IWDA**（iShares MSCI World） | 阿姆斯特丹，欧元 |

    UCITS ETF 在**欧洲交易所、欧洲交易时间**（大约 9:00–17:30 巴黎时间）交易，不是美股时段。详见 [美股 vs A股](../01-foundations/01-us-vs-a-share.md)。所以下面的练习用**美国个股**做美股时段的下单练习，ETF 用 UCITS 版本另外练。

## 6. 动手：在模拟盘下 5 笔单

下面每一步都在**模拟盘（DU 账号）**里做。具体订单类型的原理下周讲，本周只求“走通流程”。

### 第 1 笔：用限价单买入 10 股 AAPL

苹果是全球流动性最好的个股之一，价差通常只有 1 美分，最适合练手。

1. 在自选股里搜索 `AAPL`，选交易所显示为 **NASDAQ**、路由为 **SMART** 的那一个（看到 “APPLE INC” 就对了）。
2. 点 **Buy（买入）**，弹出下单窗口。
3. 按下表填写：

| 字段 | 填写 | 说明 |
|---|---|---|
| Action | BUY | 买入 |
| Quantity | 10 | 股数 |
| Order Type | LMT（限价） | |
| Limit Price | 比当前 Ask 低 0.10 | 先挂一个不会立刻成交的价格，观察订单状态 |
| Time in Force | DAY | 当日有效 |

4. 点 **Submit / Transmit**，会弹出**订单预览**（Order Preview），里面有预计佣金、交易后的现金余额、保证金影响。**仔细读一遍再确认**。
5. 在 **Orders（订单）** 面板里看订单状态。

订单状态颜色（TWS / Desktop 通用的大致含义）：

| 状态 | 含义 |
|---|---|
| Submitted（蓝/绿） | 已到交易所，等待成交 |
| Filled | 全部成交 |
| PartiallyFilled | 部分成交 |
| Cancelled | 已撤销 |
| PreSubmitted / Inactive | 未到交易所（例如非交易时段、条件未触发、参数有误） |

### 第 2 笔：修改订单

把第 1 笔的限价改成**等于当前 Ask**，确认后观察它变成 Filled。A股改单要“撤单再下”，IBKR 可以**直接修改**（Modify），保留原订单号。

### 第 3 笔：买碎股

1. 搜索一只高价股，例如 `AVGO` 或 `COST`。
2. 下单窗口里把数量改成按金额下单（Cash Quantity / 以金额计），比如 **300 美元**。
3. 成交后看持仓，会显示类似 0.33 股。

!!! warning "碎股的限制"
    碎股通常只能在常规时段交易，某些订单类型不支持，转仓到别的券商时也可能被强制卖出。适合小额定投，不适合频繁交易。

### 第 4 笔：卖出一半 AAPL

卖出 5 股 AAPL，用限价单，价格设为当前 Bid。成交后看持仓变成 5 股，再到 **Trades / Activity（成交记录）** 里找到这笔卖出的**已实现盈亏（Realized P&L）**。

### 第 5 笔：挂一个“条件不满足”的单

买入 1 股 `MSFT`，限价设成比现价低 10%。这个单大概率今天成不了交。收盘后看它的状态变成 **Cancelled（过期）**，这就是 DAY 订单的行为。下周学 GTC 时你会再做一次对比。

### 6.1 看懂持仓（Portfolio）页面

| 字段 | 中文 | 例子 | 说明 |
|---|---|---|---|
| Position | 持仓数量 | 5 | |
| Avg Price / Avg Cost | 平均成本 | 571.20 | 含不含佣金看设置 |
| Last / Mkt Price | 现价 | 575.00 | |
| Market Value | 市值 | 2,875.00 | 5 × 575 |
| Unrealized P&L | 浮动盈亏 | +19.00 | (575 − 571.20) × 5 |
| Realized P&L | 已实现盈亏 | +3.50 | 已卖出部分 |
| Daily P&L | 当日盈亏 | | 相对昨收 |

### 6.2 看懂账户（Account）页面的几个关键数字

| 英文 | 中文 | 你需要关心的原因 |
|---|---|---|
| Net Liquidation Value (NLV) | 净清算价值 | 你账户“现在全部卖掉值多少钱”，最重要的总数 |
| Cash / Total Cash | 现金 | 分币种显示：EUR、USD 各多少 |
| Settled Cash | 已交收现金 | 美股 T+1 交收，卖出后次日才“已交收” |
| Buying Power | 购买力 | 现金账户 = 现金；保证金账户会更大（借钱） |
| Excess Liquidity | 剩余流动性 | 保证金账户里，低于 0 会被强平，阶段三重要 |

## 7. 行情数据订阅：要不要花钱

IBKR 的行情是**单独收费**的，这点和A股免费 Level-1 不同。对你这样的长期投资者：

- **默认就有**：大部分美股有一个免费的实时报价来源（来自部分交易所，而不是全市场汇总），以及延迟 15 分钟的行情。日常买卖股票、ETF 基本够用。
- **常见付费包**：美国证券快照与期货价值包（US Securities Snapshot and Futures Value Bundle）、美国期权（OPRA）行情等，一般每月几美元到十几美元，部分包在当月佣金达到一定金额时可以减免。
- **非专业用户（Non-Professional）**：开通行情时会问你是不是专业投资者。你是个人投资者，选 **Non-Professional**，价格便宜很多。**选错会被按专业用户收费**。

建议：**阶段二不订阅任何付费行情**；阶段三开始交易期权前，再订阅期权行情（期权没有实时报价基本没法下限价单）。具体价格以 Client Portal → Settings → Market Data Subscriptions 页面为准，经常调整。

## 8. 常见坑

1. **在真实账户里“练习”**：下单前不看账号。解决：模拟盘和真实账户用不同的颜色主题，或者真实账户的软件只装在手机上。
2. **模拟盘用 100 万美元练**：练出来的仓位全是错的。解决：重置成和你计划一致的金额。
3. **模拟盘成交太“理想”**：模拟盘的成交逻辑是简化的，限价单有时比真实情况更容易成交，盘前盘后和小盘股尤其如此。模拟盘练的是**流程**，不是**收益**。
4. **以为 Bid/Ask 是成交价**：市价买入是按 Ask 成交，市价卖出是按 Bid 成交，中间的价差就是成本。
5. **忘记换汇**：账户里只有欧元时买美股，IBKR 可能会自动借入美元（产生负的 USD 余额，要付利息）。真实账户买美股之前，先手动换汇，第 7 周详讲。
6. **行情选成 Professional**：每月费用可能高出十倍以上。
7. **想买 SPY 被拒**：不是账户出错，是 PRIIPs 规定，换 UCITS 版本（见第 6 节开头）。
8. **重复下单**：网络慢时连点两次 Submit。解决：下单后先去 Orders 面板确认，再决定要不要重下。

### 自测题

1. 你在巴黎时间晚上 23:00 看到某股 “+6% Post”，这是什么意思？第二天巴黎时间几点能在常规时段交易？

3. 你的账号是 DU 开头还是 U 开头时，下单会花真钱？

??? success "答案"
    1. 盘后交易时段比前一日收盘价涨 6%，通常是财报或重大消息。第二天常规时段巴黎时间 15:30 开盘（夏令时错位周为 14:30），盘前从 10:00 起也能交易，但流动性差。
    2. 价差 0.10 × 200 = 20 美元。
    3. U 开头是真实账户；DU 开头是模拟账户。
