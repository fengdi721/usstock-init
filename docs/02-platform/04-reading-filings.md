## 1. 和A股对比

| 方面 | A股 | 美股 |
|---|---|---|
| 官方披露网站 | 巨潮资讯网（cninfo）、交易所网站 | **SEC EDGAR**（sec.gov） |
| 年报 | 年度报告，4 月 30 日前 | **10-K**，财年结束后 60–90 天内（大公司 60 天） |
| 季报 / 半年报 | 一季报、半年报、三季报 | **10-Q**，前三个财季各一份，季末后 40–45 天内；第四季度包含在 10-K 里 |
| 临时公告 | 各类临时公告 | **8-K**（重大事件，4 个工作日内） |
| 业绩预告 | 业绩预告、快报（强制情形多） | 没有强制预告；公司在财报里**主动给下季指引（Guidance）** |
| 财报发布方式 | 直接发布定期报告 | 先发**新闻稿**（作为 8-K 附件），当天开**电话会**，几天到几周后再交 10-Q / 10-K |
| 会计准则 | 中国企业会计准则 | **US GAAP**；公司常额外提供 **Non-GAAP**（调整后）数字 |
| 财年 | 统一自然年 | **各公司自己定**：苹果财年截至 9 月最后一个周六，微软截至 6 月 30 日 |
| 外国公司 | — | 交 **20-F**（年报）和 **6-K**（临时），例如台积电、阿里巴巴 |
| 市场关注点 | 净利润增速、题材 | **和分析师预期比**：超预期（Beat）还是不及（Miss），以及**指引** |

最大的思维转变：**美股财报日股价涨跌，取决于“实际 vs 预期”，以及“下季指引 vs 预期”，而不是“好不好”**。利润增长 30% 但预期是 35%，股价可能大跌。

## 2. 你需要认识的文件

### 2.1 核心三件套

| 文件 | 是什么 | 多长 | 你要读什么 |
|---|---|---|---|
| **10-K** | 年报，经审计 | 80–150 页 | 业务介绍、风险因素、管理层讨论（MD&A）、三张报表 |
| **10-Q** | 季报，未审计（审阅） | 40–80 页 | 三张报表、MD&A 的变化部分 |
| **8-K** | 重大事件公告 | 几页 | 看 Item 编号判断事件类型 |

### 2.2 8-K 常见 Item 编号

| Item | 内容 | 重要性 |
|---|---|---|
| **2.02** | 经营业绩（**财报新闻稿就在这里**） | ★★★ |
| 1.01 | 签订重大协议（并购、大合同） | ★★ |
| 2.01 | 完成收购或出售资产 | ★★ |
| 5.02 | 高管或董事变动（CEO 离职） | ★★ |
| 7.01 | Reg FD 披露（投资者日材料等） | ★ |
| 8.01 | 其他事项（如回购计划、分红） | ★ |
| 1.03 | 破产 | ★★★ |
| 4.02 | 之前的财报不可信，需要重述 | ★★★（红色警报） |

### 2.3 其他值得知道的文件

| 文件 | 内容 | 用处 |
|---|---|---|
| **DEF 14A**（Proxy Statement） | 股东大会委托书 | 高管薪酬、董事会、股东提案 |
| **Form 4** | 内部人（高管、董事、10% 股东）买卖股票 | 内部人**大额买入**是值得注意的信号；卖出很常见，意义小 |
| **13F** | 管理资产超 1 亿美元的机构每季度持仓 | 看巴菲特（伯克希尔）买了什么；有 45 天延迟 |
| **S-1 / F-1** | IPO 招股书 | 新股研究 |
| **SC 13D / 13G** | 持股超 5% 的股东 | 13D 是“积极”股东，可能要干预公司 |
| **20-F / 6-K** | 外国公司的年报 / 临时报告 | 台积电（TSM）、阿斯麦（ASML）等 |

## 3. 动手：用 EDGAR 找到苹果的文件

1. 打开 `sec.gov`，用 **EDGAR Full-Text Search** 或首页的公司搜索，输入 `AAPL` 或 `Apple Inc`。
2. 进入公司页面，你会看到按时间排列的所有文件，可以按 **Filing Type**（文件类型）筛选，输入 `10-K`。
3. 点开最近一份 10-K，选 **Document**（主文件，HTML 格式）。
4. 文件开头有一个**目录（Table of Contents）**，点链接即可跳到各部分。

!!! tip "更省事的阅读入口"
    - 公司官网的 **Investor Relations（投资者关系）** 页面，例如 `investor.apple.com`：新闻稿、PPT、电话会录音一站式。
    - EDGAR 每份 10-K/10-Q 都有 **Financial Report（R 文件）** 或 **Interactive Data** 链接，三张报表可以直接看表格，甚至下载 Excel。
    - 浏览器翻译插件可以整页翻成中文，但**数字和表格一定要看原文**。

### 3.1 财报季时间线（以一个典型的大公司为例）

```
季末 ─────── 约 3-5 周 ───────► 财报日 ──── 同日 ────► 电话会 ── 数日至数周 ──► 10-Q 提交
(如 9月27日)                      (如 10月30日 盘后)       (美东 17:00)                (11月初)
                                  ├ 8-K（Item 2.02）
                                  └ 新闻稿 + 财务报表摘要 + 指引
```

- 大部分公司在**盘后**（巴黎时间 22:05 左右）或**盘前**（巴黎时间 13:00–14:30）发布。
- **财报季**：每年 1 月中、4 月中、7 月中、10 月中开始，持续约 6 周。大银行（摩根大通等）最先发，科技巨头一般在第 2–3 周。

## 4. 苹果 10-K 拆解

以下数字来自苹果 **2024 财年**（截至 2024 年 9 月 28 日）10-K，单位**十亿美元**，四舍五入。请你打开原文逐项对照，并**用最新一份 10-K 重新填一遍**，这本身就是最好的练习。

### 4.1 10-K 的结构（所有公司都一样）

| 部分 | Item | 内容 | 阅读优先级 |
|---|---|---|---|
| Part I | **Item 1 Business** | 业务介绍：卖什么、怎么赚钱 | ★★★ 第一次研究一家公司必读 |
| | **Item 1A Risk Factors** | 风险因素 | ★★ 浏览标题，留意**新增**的风险 |
| | Item 1C Cybersecurity | 网络安全 | ★ |
| | Item 3 Legal Proceedings | 重大诉讼 | ★ |
| Part II | Item 5 Market for Equity | 股票回购、分红 | ★ |
| | **Item 7 MD&A** | 管理层讨论与分析：为什么增长、为什么下降 | ★★★ **最有价值的部分** |
| | Item 7A Market Risk | 汇率、利率风险 | ★ |
| | **Item 8 Financial Statements** | 三张报表 + 附注 | ★★★ |
| | Item 9A Controls | 内部控制 | ★（出问题时才重要） |
| Part III | Item 10–14 | 董事、高管薪酬（通常引用 Proxy） | ★ |

### 4.2 Item 1：苹果靠什么赚钱

按产品分的收入（FY2024）：

| 类别 | 收入 | 占比 |
|---|---|---|
| iPhone | 201.2 | 51% |
| Mac | 30.0 | 8% |
| iPad | 26.7 | 7% |
| 可穿戴、家居和配件 | 37.0 | 9% |
| **服务**（App Store、iCloud、Apple Music、广告、AppleCare、支付等） | **96.2** | **25%** |
| **合计** | **391.0** | 100% |

按地区分：

| 地区 | 收入 | 占比 |
|---|---|---|
| 美洲 | 167.0 | 43% |
| 欧洲（含印度、中东、非洲） | 101.3 | 26% |
| 大中华区 | 67.0 | 17% |
| 日本 | 25.1 | 6% |
| 亚太其他 | 30.7 | 8% |

**读出来的结论**：
1. 苹果依然是“iPhone 公司”，一半收入来自 iPhone。
2. 服务只占 25% 的收入，但毛利率高得多（见下），利润贡献远超 25%。
3. 大中华区 17%，所以中国市场的竞争和政策是重要风险。

### 4.3 Item 8：利润表（Income Statement）

| 项目（英文） | 中文 | FY2024 | FY2023 | 变化 |
|---|---|---|---|---|
| Net sales | 营业收入 | 391.0 | 383.3 | +2.0% |
| Cost of sales | 营业成本 | 210.4 | 214.1 | |
| **Gross margin** | **毛利** | **180.7** | 169.1 | +6.8% |
| Research and development | 研发费用 | 31.4 | 29.9 | |
| Selling, general and administrative | 销售及管理费用 | 26.1 | 24.9 | |
| **Operating income** | **营业利润** | **123.2** | 114.3 | +7.8% |
| Other income/(expense) | 其他收支 | 0.3 | −0.6 | |
| Provision for income taxes | 所得税 | 29.7 | 16.7 | ⚠️ |
| **Net income** | **净利润** | **93.7** | 97.0 | **−3.4%** |
| Diluted EPS | 稀释每股收益（美元） | 6.08 | 6.13 | −0.8% |

**算几个比率**：

\[
\text{毛利率} = \frac{180.7}{391.0} = 46.2\% \qquad \text{营业利润率} = \frac{123.2}{391.0} = 31.5\%
\]

10-K 里还分别披露了产品和服务的毛利率：产品约 **37%**，服务约 **74%**。这就是为什么市场如此关注苹果的服务收入增速。

**发现问题：营业利润增长 7.8%，净利润却下降 3.4%，为什么？**

看所得税一行：从 16.7 跳到 29.7。翻到 MD&A 和税务附注，会找到原因：欧盟法院就爱尔兰税务案作出最终裁决，苹果在 2024 财年确认了一笔约 **102 亿美元的一次性所得税费用**。剔除它：

\[
\text{调整后净利润} \approx 93.7 + 10.2 = 103.9 \quad (\text{同比约} +7\%)
\]

这就是读财报的意义：**只看标题数字“净利润下降”会得出错误结论**，原因藏在附注里。这类一次性项目也是公司提供 Non-GAAP 数字的理由（第 5.3 节）。

### 4.4 Item 8：资产负债表（Balance Sheet，截至 2024-09-28）

| 项目 | 金额 | 说明 |
|---|---|---|
| 现金及现金等价物 | 29.9 | |
| 短期有价证券 | 35.2 | 主要是国债、公司债 |
| 长期有价证券 | 91.5 | |
| **现金 + 投资合计** | **约 156.6** | |
| 总资产 | 365.0 | |
| 商业票据 + 长短期债务 | 约 106.6 | |
| 总负债 | 308.0 | |
| **股东权益** | **57.0** | 很小！ |

**有意思的地方**：苹果的股东权益只有 570 亿美元，相对 3 万多亿的市值非常小。原因是苹果多年来把利润大量用于**回购股票**，回购会减少股东权益。所以苹果的“净资产收益率（ROE）”高达 160% 以上，这个数字不说明它比别的公司“好”十倍，而是分母被回购压小了。第 9 周会讲为什么 ROE 要和其他指标一起看。

**净现金**：156.6 − 106.6 ≈ **50**（十亿美元）。苹果是“净现金”公司，财务极其稳健。

### 4.5 Item 8：现金流量表（Cash Flow Statement）

| 项目 | FY2024 | 说明 |
|---|---|---|
| **经营活动现金流**（Cash generated by operating activities） | **118.3** | |
| 购建固定资产（Payments for PP&E，即资本开支 Capex） | −9.4 | |
| **自由现金流 FCF** = 经营现金流 − 资本开支 | **108.8** | 真正“可自由支配”的钱 |
| 回购股票（Repurchases of common stock） | −94.9 | |
| 分红（Payments for dividends） | −15.2 | |
| 回购 + 分红合计 | −110.2 | 约等于全部自由现金流 |

**结论**：苹果每年产生约 1,090 亿美元自由现金流，**几乎全部还给股东**（回购为主，分红为辅）。回购让总股数每年减少约 2–3%，所以即使净利润不增长，**每股收益（EPS）也会慢慢上升**。

### 4.6 Item 7 MD&A：去找“为什么”

MD&A 里有几段你每次都应该找：

- **Segment Operating Performance**：各地区收入变化及原因。
- **Products and Services Performance**：各产品线变化及原因（例如“iPad 下降主要因为型号组合…”）。
- **Gross Margin**：毛利率变化的原因（成本、汇率、产品组合）。
- **Liquidity and Capital Resources**：现金、债务、回购计划。

读的方法：**先看数字表，再找它下面那一两句“due to / primarily driven by / partially offset by”**。这几个短语后面就是原因。

### 4.7 Item 1A 风险因素：怎么读才不浪费时间

苹果的风险因素有 15 页以上，大部分是每年重复的套话。高效方法：

1. 只看每段的**粗体标题**。
2. 打开去年的 10-K，**对比标题有没有新增或改写**。新增的风险往往是管理层真正担心的事（例如关税、反垄断诉讼、AI 竞争）。

## 5. 财报新闻稿（8-K Item 2.02）：财报日真正要看的东西

10-K 一年一次，而且比新闻稿晚几周。财报当天，市场反应的是**新闻稿**。一份典型的苹果新闻稿只有 5–6 页：

1. **标题**：例如 *Apple reports fourth quarter results*。
2. **第一段**：本季收入、EPS 及同比变化。
3. **CEO / CFO 引语**：管理层想让你记住的亮点（会挑好的说）。
4. **分红公告**：宣布下一次季度股息。
5. **三张简化报表**：比 10-Q 简化，但数字一样。
6. （很多公司还有）**下季指引**和 **Non-GAAP 调节表**。苹果不在新闻稿里给正式数字指引，而是在电话会里口头给出方向。

### 5.1 “超预期”是什么意思

财经网站在财报出来后会写这样的标题：

> *Apple beats on revenue and EPS, but iPhone sales miss; stock falls 2% after hours.*

拆解：

| 指标 | 实际 | 分析师一致预期（Consensus） | 结果 |
|---|---|---|---|
| 收入 | 94.9 | 94.5 | Beat（超出 0.4%） |
| EPS | 1.64 | 1.60 | Beat |
| iPhone 收入 | 46.2 | 46.5 | Miss |

（表中为说明格式的示意数字。）

**一致预期**是多家分析师预测的平均值，在 Yahoo Finance 等网站的 *Analysis* / *Earnings* 页面可以查到。市场早已把一致预期“计入股价”，所以：

- 小幅超预期 → 往往股价不怎么动，甚至下跌（“利好出尽”，A股也有这个说法）。
- 指引低于预期 → 即使本季很好，股价也常常大跌。
- 关键分项（苹果的 iPhone、大中华区、服务）低于预期 → 可能比总数更重要。

### 5.2 用数字看“预期差”如何决定股价

假设一家公司：

| | 本季 EPS | 下季指引 EPS | 盘后股价 |
|---|---|---|---|
| 市场预期 | 2.00 | 2.20 | — |
| 情景 A：实际 | 2.10（+5%） | 2.30 | **+6%** |
| 情景 B：实际 | 2.10（+5%） | 2.05 | **−9%** |
| 情景 C：实际 | 1.95（−2.5%） | 2.40 | **+4%** |

规律：**未来比过去重要**。情景 C 本季不及预期，但指引大超预期，股价反而上涨。

### 5.3 GAAP 与 Non-GAAP

很多公司（尤其是科技公司）会同时公布：

- **GAAP**：严格按会计准则。
- **Non-GAAP / Adjusted（调整后）**：剔除股权激励费用、并购摊销、一次性费用等。

**例子**：某软件公司本季

| | GAAP | 调整项 | Non-GAAP |
|---|---|---|---|
| 营业利润 | 100 | + 股权激励 80 + 并购无形资产摊销 20 | 200 |
| EPS | 0.50 | | 1.00 |

Non-GAAP EPS 是 GAAP 的两倍。华尔街的“一致预期”通常对的是 Non-GAAP 数字。

!!! warning "对 Non-GAAP 保持怀疑"
    股权激励（Stock-Based Compensation，SBC）是**真实成本**：公司用股票付工资，摊薄了你的持股。有些公司 SBC 占收入 20% 以上，Non-GAAP 利润看起来很美，实际股东价值被持续稀释。阅读时**两个数字都要看**，并检查调节表里剔除了什么。苹果的 SBC 约占收入 3%，相对较低。

## 6. 财报电话会（Earnings Call）

### 6.1 结构

| 环节 | 时长 | 内容 |
|---|---|---|
| 开场 | 1–2 分钟 | IR 负责人宣读免责声明（*forward-looking statements…*） |
| CEO 发言 | 5–10 分钟 | 战略、亮点、新产品 |
| CFO 发言 | 5–10 分钟 | 详细财务数字、**指引** |
| **问答（Q&A）** | 30–45 分钟 | 分析师提问，**最有信息量** |

### 6.2 怎么听 / 读

- **文字稿（Transcript）**：财报后几小时内会出现在 Seeking Alpha、Motley Fool、公司 IR 网站或部分券商研究平台上，有的需要注册。**先读文字稿**，英语压力小很多。
- **录音**：公司 IR 网站一般保留回放。阶段三之后，英语课会用电话会做听力练习，见 [衍生品英语与听力](../00-english/04-options-english-and-listening.md)。

### 6.3 Q&A 里要留意的信号

| 信号 | 例子 | 可能的含义 |
|---|---|---|
| 分析师集中追问同一个问题 | 连续 3 个人问中国市场 | 这是市场最担心的点 |
| 管理层回避具体数字 | *We don't break that out.* | 数字可能不好看 |
| 语气变化 | 上季说 *strong demand*，本季说 *solid demand* | 需求可能在放缓 |
| 新词出现 | 第一次频繁提到 *pricing actions*（提价） | 可能面临成本压力 |
| 指引范围变宽 | 从 “+5% 到 +7%” 变成 “+3% 到 +8%” | 不确定性上升 |

## 7. 一套固定的“财报日阅读流程”（30 分钟版）

财报发布后，按这个顺序：

1. **5 分钟**：读财经新闻标题（Reuters、CNBC），知道 Beat/Miss 和盘后股价反应。
2. **10 分钟**：打开新闻稿，自己核对收入、毛利率、营业利润、EPS、各分项，以及指引。
3. **10 分钟**：读电话会文字稿的 CFO 部分和 Q&A 前 5 个问题。
4. **5 分钟**：在笔记里写三句话：发生了什么？为什么？我的看法是否需要改变？

10-Q / 10-K 出来后（一般几周后），再花 30–60 分钟补读 MD&A 和附注。

## 8. 常见坑

1. **只看净利润同比**：苹果 FY2024 净利润下降，但原因是一次性税费（第 4.3 节）。
2. **不看财年**：苹果“2025 财年第一季度”是 2024 年 10–12 月。看到 *Q1 FY2025* 先换算日期。
3. **把 Non-GAAP 当真实利润**：检查调节表，尤其是股权激励。
4. **只看总数不看分项**：总收入 Beat，但最重要的业务 Miss，股价照样跌。
5. **以为“好财报 = 涨”**：取决于和预期的差，以及指引。
6. **看风险因素看到睡着**：只比较新旧标题。
7. **盘后按新闻标题冲动交易**：盘后流动性差，初始反应经常在第二天被修正，甚至反转。
8. **混淆“十亿”和“百万”**：美国报表单位常写在表头 *(In millions, except per-share amounts)*。苹果报表单位是百万美元，391,035 就是 3,910 亿美元。

### 自测题

1. 你想看某公司是否宣布了新 CEO，应该找什么文件、哪个 Item？
2. 一家公司 GAAP EPS 0.80，Non-GAAP EPS 1.40，调节表显示主要差异来自股权激励。你会怎么看？
3. 苹果 FY2024 经营现金流 118.3，资本开支 9.4，回购 94.9，分红 15.2。回购 + 分红占自由现金流的百分比是多少？

??? success "答案"
    1. 8-K，Item 5.02。
    2. 股权激励费用很高，相当于 EPS 的 (1.40−0.80)/1.40 ≈ 43%。这是真实的稀释成本，应以 GAAP 为主，或者至少检查总股数是否在持续增加。
    3. 自由现金流 118.3 − 9.4 = 108.9；(94.9 + 15.2) / 108.9 ≈ **101%**。
