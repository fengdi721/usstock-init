# 第26周：开仓、调仓与退出

!!! abstract "一句话总结"
    好管理始于开仓前：如果盈利目标、观点失效、时间退出和事件退出没有预写，盘中做的“调整”通常只是推迟承认错误。

## 1. 开仓单

每笔交易必须填写：

```text
标的 / 时间：
四维观点（方向、幅度、期限、IV）：
结构 / 每一腿：
净借记或贷记：
最大盈利 / 最大亏损 / 盈亏平衡：
组合 Delta / Theta / Vega：
目标盈利：
价格失效：
时间退出：
事件退出：
指派与交割预案：
计划滑点 / 实际滑点：
```

## 2. 四种退出是不同的

| 类型 | 问题 | 示例 |
|---|---|---|
| 盈利退出 | 已获得多少潜在利润，剩余风险值得吗？ | 已拿到最大盈利的 70%，剩余 10 DTE |
| 观点失效 | 原始市场判断是否不再成立？ | Bull Spread 标的跌破基本面失效位 |
| 时间退出 | 催化剂没发生，是否还愿承担 Gamma/Theta？ | 剩余 7 DTE，无继续持有理由 |
| 事件退出 | 新事件是否改变分布？ | 财报日期提前到持仓期内 |

“亏损达到 50% 就止损”不是对所有策略通用。借方策略、贷方策略和 Calendar 的风险路径不同，但每笔都应有一个可执行的退出条件。

## 3. 调整决策树

1. 原始观点还成立吗？不成立 → 平仓。
2. 如果现在没有仓位，会以当前价格新开调整后的结构吗？不会 → 不调整。
3. 调整是否降低**总风险**，还是只降低当前账面亏损显示？
4. 新结构的最大亏损、到期日和事件风险是什么？
5. 与“立即平仓，把资金留给下一笔”相比，优势是什么？

## 4. 滚动的真实记账

原 Short Put 收到 `$1.50`，现在用 `$3.80` 买回，已实现亏损 `$230`。再卖下月 Put 收到 `$4.20`。

券商可能显示本次 Roll 净收到 `$0.40`，但事实是：

- 旧交易：`+$150-$380=-$230`；
- 新交易：收到 `$420`，同时承担一份新的下月义务；
- 新权利金不是把旧亏损“消掉”，只是新增风险换来的现金流。

## 5. 四腿结构的管理

- Iron Condor 一侧受威胁时，最简单的动作通常是整体平仓或平掉受威胁侧。
- 把未受威胁侧滚近来收更多权利金，会缩窄安全区并增加反转风险。
- 不把有限风险结构拆成裸短腿。
- 到期前整体关闭，避免 pin risk 和盘后变化造成意外交割。

## 6. 复盘只评估过程，不只评估盈亏

给每笔交易打分：

| 项目 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 观点 | 无书面观点 | 有方向，无幅度/期限 | 四维完整 |
| 风险 | 最大亏损未知 | 已知但超预算 | 已知且合规 |
| 执行 | 市价/拆腿 | 限价但无滑点记录 | 组合限价且有记录 |
| 管理 | 临时决定 | 部分规则预写 | 全部预写并执行 |
| 复盘 | 只记盈亏 | 有描述 | 区分过程与运气 |

一笔亏钱但拿到 10 分的交易，比一笔违规侥幸盈利的交易更有学习价值。
