# 第23周：波动率结构——跨式、宽跨式、蝶式与铁鹰

!!! abstract "一句话总结"
    多腿中性策略不是“稳赚结构”：Long Straddle 买的是实际波动超过隐含波动，Iron Condor 卖的是相反观点；蝶式则押一个更窄的到期落点。

## 1. Long Straddle：买入双向大波动

ABC `$100`，同一到期日：

- 买入 `100 Call @ 3.00`
- 买入 `100 Put @ 2.80`
- 总借记 `$5.80`，成本与最大亏损 `$580`
- 上方盈亏平衡 `$105.80`；下方 `$94.20`

| 到期股价 | 净盈亏 |
|---:|---:|
| `$90` | `+$420` |
| `$95` | `-$80` |
| `$100` | `-$580` |
| `$105` | `-$80` |
| `$110` | `+$420` |

它的风险不是“方向看错”，而是**动得不够多、不够快**。财报前 IV 高时买入，事件后即使股价移动，也可能因 IV crush 低于预期而亏损。

## 2. Long Strangle：更便宜，但需要更大移动

买入 `105 Call @ 1.50` 和 `95 Put @ 1.30`，总成本 `$280`。盈亏平衡为 `$107.80` 与 `$92.20`。相比跨式，成本和最大亏损较低，但盈利门槛更远。

## 3. Long Call Butterfly：押到期落在中间

- 买 1 张 `95 Call @ 6.60`
- 卖 2 张 `100 Call @ 3.20`
- 买 1 张 `105 Call @ 1.10`
- 净借记 `$1.30`，最大亏损 `$130`

| 指标 | 结果 |
|---|---:|
| 最大盈利 | `($5 - $1.30) × 100 = $370`，发生在到期恰好 `$100` |
| 盈亏平衡 | `$96.30` 与 `$103.70` |
| 最大亏损 | `$130`，在 `$95` 以下或 `$105` 以上 |

高“最大收益率”来自狭窄的最佳落点，不是免费午餐。越临近到期，价格稍动，盈亏变化越剧烈。

## 4. Iron Condor：有限风险的区间卖方

同一到期日：

- 买 `90 Put`、卖 `95 Put`；
- 卖 `105 Call`、买 `110 Call`；
- 合计净贷记 `$1.40`。

| 指标 | 结果 |
|---|---:|
| 最大盈利 | `$140`，到期位于 `$95–105` |
| 最大亏损 | `($5 - $1.40) × 100 = $360` |
| 盈亏平衡 | `$93.60` 与 `$106.40` |

风险回报是“最多赚 `$140`，可能亏 `$360`”。一次满亏约抵消 2.6 次满盈，所以只看高胜率会误导。

## 5. Expected Move 不是保证区间

用近月 ATM Straddle 价格粗估市场隐含移动：Call `$3.00` + Put `$2.80` = `$5.80`，即约 ±5.8%。这是价格反映的预期尺度，不是“有 100% 概率不会越界”。

开 Iron Condor 前至少问：

- 短行权价是否只机械放在 expected move 外？
- IV 是否真的相对自身历史偏高？
- 区间内是否有财报、监管裁决等跳空事件？
- 四腿滑点后，净贷记是否仍值得？
- 触及短腿、损失达到多少或剩余多少 DTE 时退出？

## 6. 新手规则

- Long Straddle/Strangle：最大亏损就是全部借记，但不要因此忽略高损失概率。
- Iron Condor：始终买保护翼；不用“到期一定回来”作为理由扛单。
- Butterfly：用于理解落点与凸性，先模拟，不把最大理论收益当预期收益。
- 任何四腿结构都必须用组合限价单整体进出。

## 7. 练习

Iron Condor 的翼宽 `$5`，收到 `$1.10`。求最大盈利、最大亏损；若计划在亏损达到收到权利金的 2 倍时退出，计划损失是多少？

??? success "答案"
    最大盈利 `$110`；最大亏损 `($5-$1.10)×100=$390`；“亏损达到贷记 2 倍”通常指头寸净亏约 `$220`。实际跳空可能越过止损，限价也不保证成交。
