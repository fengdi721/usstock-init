# 第30周：建立个人期权策略手册

!!! abstract "一句话总结"
    熟练交易者不是策略最多的人，而是只在少数可重复场景中行动、清楚知道何时不做的人。

## 1. 我的允许清单（初始版）

| 等级 | 策略 | 前置条件 | 实盘状态 |
|---|---|---|---|
| A | Protective Put / Collar | 已持股，保护目的明确 | 模拟通过后可评估 |
| A | Bull Call / Bear Put Spread | 明确方向、目标价、有限借记 | 模拟通过后可评估 |
| A | Covered Call | 真愿意按行权价卖 100 股 | 模拟通过后可评估 |
| A | Cash-Secured Put | 真愿意持有且集中度合规 | 小账户通常不适合 |
| B | Calendar / Diagonal | 会处理指派与期限结构 | 仅模拟 |
| B | Long Straddle / Strangle | 有波动率观点，不只猜方向 | 仅模拟 |
| B | Butterfly / Iron Condor | 会管理四腿与到期风险 | 仅模拟 |
| 禁止 | Naked Call/Put、Short Straddle、Ratio 裸腿 | 风险未定义/可能极大 | 不做 |
| 禁止 | 0DTE 冲动交易 | Gamma、滑点和行为风险高 | 不做 |

“可评估”不等于推荐实盘；还要满足毕业标准、资金规模和券商权限。

## 2. 标的准入

- 我能解释标的是什么，愿意承担对应风险；
- 期权链流动性可接受，价差不过宽；
- 没有未处理的财报、除息、并购、拆股等事件；
- 标准 100 股乘数与账户规模相容；
- 不用 meme 股或极端高 IV 标的练习“收租”。

## 3. 开仓检查清单

- [ ] 四维观点和不交易条件已写；
- [ ] 每一腿、到期、行权价、数量核对；
- [ ] 最大盈亏、盈亏平衡和 Greeks 已算；
- [ ] 最坏亏损与指派现金需求符合预算；
- [ ] 财报、除息、宏观事件和到期处理已查；
- [ ] 使用组合限价单，记录 Mid 与最大可接受滑点；
- [ ] 盈利、失效、时间、事件四类退出已写；
- [ ] 能用一句话说明为什么不选更简单的结构。

## 4. 持仓与退出检查清单

每日只检查事件和是否触发规则，不因每个 tick 改计划。每周更新组合 Greeks 和压力测试。任何调整先回答：“若现在空仓，我会新开调整后的仓位吗？”

平仓后记录：

```text
开/平仓日期与成交：
毛盈亏 / 佣金 / 滑点 / 净盈亏：
原始观点是否正确：
策略选择是否正确：
执行是否合规：
最大不利/有利变动：
若重做，只改变哪一条：
过程评分（0–10）：
```

## 5. 规则版本管理

不要因一笔亏损改规则。每 20 笔为一个样本批次，只在批次复盘时调整，并保留版本：

- v0.1：模拟盘初始规则；
- v0.2：基于 20 笔证据，只修改一到两项；
- v1.0：连续两个样本批次规则执行率达标后，才考虑最小规模实盘。

策略收益不佳可能来自行情样本，不等于规则错误；违规却盈利也不等于规则应放宽。

## 6. 暂停条件

出现任一项，停止开新仓并复盘：连续 3 次违规、单笔超预算、无法解释当前组合风险、为了回本加仓、睡眠受影响、券商出现未理解的交割/保证金提示。
