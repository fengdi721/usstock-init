# 第30周：建立个人期权策略手册

!!! abstract "一句话总结"
    熟练交易者不是策略最多的人，而是只在少数可重复场景中行动、清楚知道何时不做的人。

## 1. 我的允许清单（初始版）

| 等级 | 策略 | 前置条件 | 实盘状态 |
|---|---|---|---|
| A | Protective Put / Collar | 已持股，保护目的明确 | 模拟通过后可评估 |
| A | Bull Call / Bear Put Spread | 明确方向、目标价、有限借记 | 模拟通过后可评估 |
| A | Covered Call | 真愿意按行权价卖 100 股 | 模拟通过后可评估 |
| A | Cash-Secured Put | 真愿意持有且集中度合规 | 小账户通常不适合 |
| B | Calendar / Diagonal | 会处理指派与期限结构 | 仅模拟 |
| B | Long Straddle / Strangle | 有波动率观点，不只猜方向 | 仅模拟 |
| B | Butterfly / Iron Condor | 会管理四腿与到期风险 | 仅模拟 |
| 禁止 | Naked Call/Put、Short Straddle、Ratio 裸腿 | 风险未定义/可能极大 | 不做 |
| 禁止 | 0DTE 冲动交易 | Gamma、滑点和行为风险高 | 不做 |

“可评估”不等于推荐实盘；还要满足毕业标准、资金规模和券商权限。

## 2. 标的准入

- 我能解释标的是什么，愿意承担对应风险；
- 期权链流动性可接受，价差不过宽；
- 没有未处理的财报、除息、并购、拆股等事件；
- 标准 100 股乘数与账户规模相容；
- 不用 meme 股或极端高 IV 标的练习“收租”。

## 3. 开仓检查清单

- [ ] 四维观点和不交易条件已写；
- [ ] 每一腿、到期、行权价、数量核对；
- [ ] 最大盈亏、盈亏平衡和 Greeks 已算；
- [ ] 最坏亏损与指派现金需求符合预算；
- [ ] 财报、除息、宏观事件和到期处理已查；
- [ ] 使用组合限价单，记录 Mid 与最大可接受滑点；
- [ ] 盈利、失效、时间、事件四类退出已写；
- [ ] 能用一句话说明为什么不选更简单的结构。

## 4. 持仓与退出检查清单

每日只检查事件和是否触发规则，不因每个 tick 改计划。每周更新组合 Greeks 和压力测试。任何调整先回答：“若现在空仓，我会新开调整后的仓位吗？”

平仓后记录：

```text
开/平仓日期与成交：
毛盈亏 / 佣金 / 滑点 / 净盈亏：
原始观点是否正确：
策略选择是否正确：
执行是否合规：
最大不利/有利变动：
若重做，只改变哪一条：
过程评分（0–10）：
```

## 5. 规则版本管理

不要因一笔亏损改规则。每 20 笔为一个样本批次，只在批次复盘时调整，并保留版本：

- v0.1：模拟盘初始规则；
- v0.2：基于 20 笔证据，只修改一到两项；
- v1.0：连续两个样本批次规则执行率达标后，才考虑最小规模实盘。

策略收益不佳可能来自行情样本，不等于规则错误；违规却盈利也不等于规则应放宽。

## 6. 暂停条件

出现任一项，停止开新仓并复盘：连续 3 次违规、单笔超预算、无法解释当前组合风险、为了回本加仓、睡眠受影响、券商出现未理解的交割/保证金提示。

## 7. 完整示例：把一个模糊想法写成可执行 Playbook

### 模糊想法

> “科技股最近挺强，我想买个 Call，涨了就卖。”

这个想法无法执行，因为没有目标幅度、有效期限、IV 判断、风险预算和退出条件。

### 改写后的交易卡

```text
标的：ABC，现价 $100
观点：未来 30 天温和上涨至 $104–106；若跌破 $97，观点失效
波动率：IV 处于自身中位附近，不跨财报
结构：Long 100 Call / Short 105 Call，同到期
最大净借记：$1.90（$190）
最大盈利：$310；盈亏平衡：$101.90
组合初始 Delta：约 +22；净 Theta 与 Vega 均小于裸买 Call
盈利退出：组合价格到 $4.00 后平仓
失效退出：ABC 收盘低于 $97
时间退出：剩余 7 DTE
事件退出：新增财报、监管或并购事件时退出/重评
执行：组合限价，从 $1.75 开始，最高不超过 $1.90
```

现在它才是可以被审计的计划。即使最后亏损，也能判断是观点、结构、执行还是随机结果的问题。

## 8. 示例：一次违规盈利如何记录？

交易者原计划最多支付 `$1.50` 买 Call，但因股价快速上涨，用市价单成交 `$2.10`；没有写退出条件。后来 Call 涨到 `$3.00`，盈利 `$90`。

日志应同时记录：

- 财务结果：`+$90`；
- 过程结果：违规；
- 违规一：追价超过最大允许成本，实际风险从 `$150` 增至 `$210`；
- 违规二：使用市价单，无法控制滑点；
- 违规三：无退出规则；
- 结论：不能因为盈利而把这套行为加入允许清单。

如果只记录“盈利 43%”，Playbook 会奖励危险行为。

## 9. 示例：规则冲突时的优先级

假设持仓同时触发：

- 盈利达到目标，应该平仓；
- 你刚看到一条利好新闻，想继续持有；
- 明天又是财报，规则禁止跨财报。

建议固定优先级：

1. 账户生存与最大风险；
2. 事件和交割禁令；
3. 观点失效；
4. 时间退出；
5. 盈利目标；
6. 新出现但尚未验证的主观判断。

因此按计划平仓。若利好形成新的交易机会，应在旧仓关闭后重新写一张交易卡，而不是临时改写旧交易理由。

## 10. 20 笔样本汇总模板

| # | 策略 | 四维观点完整 | 风险合规 | 执行合规 | 退出合规 | 净盈亏 | 过程分 |
|---:|---|---|---|---|---|---:|---:|
| 1 | Bull Call | 是 | 是 | 是 | 是 | `+$80` | 10 |
| 2 | Iron Condor | 是 | 是 | 否 | 是 | `+$40` | 8 |
| 3 | Calendar | 否 | 是 | 是 | 否 | `-$55` | 5 |

汇总时至少计算：规则执行率、平均盈利、平均亏损、最大亏损、最大回撤、按策略分类结果、按事件分类结果。20 笔不足以证明长期统计优势，但足以暴露重复违规。

## 11. 本章练习

把以下句子改成完整交易卡：“我觉得 ABC 不会跌破 `$90`，所以想卖 Put。”至少补齐 10 个缺失字段。

??? success "参考检查点"
    应补：现价、目标期限、为什么 `$90` 有效、Put 到期日与行权价、权利金、最大亏损、现金占用、账户集中度、财报/除息、是否真愿持股、盈利/失效/时间/事件退出、限价与滑点、指派预案。若任何关键项不清楚，先不交易。
