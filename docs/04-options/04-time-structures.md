# 第24周：时间结构——Calendar、Diagonal 与 PMCC

!!! abstract "一句话总结"
    时间价差不是简单地“卖快、买慢”：它同时交易两个到期月的 Theta、Vega 和隐含波动率期限结构，短腿还可能被提前指派。

## 1. Long Call Calendar

ABC `$100`：

- 卖出 30 DTE `100 Call @ 3.00`
- 买入 90 DTE `100 Call @ 6.00`
- 净借记 `$3.00`，即 `$300`

理想情景是近月到期时 ABC 接近 `$100`：短 Call 的时间价值快速衰减，长 Call 仍保留较多时间价值。它通常初始 Theta 为正、Vega 为正，但具体数值取决于报价。

不能用普通垂直价差公式计算固定最大盈利，因为近月到期时长腿仍有时间价值，取决于股价和届时 IV。风险图必须指定“估值日期”。

### 失败剧本

- ABC 很快涨到 `$115`：短 Call 深度价内，Delta 接近 -1；长 Call 虽上涨，但两个期限的变化不完全同步。
- ABC 跌到 `$85`：两腿均价外，长 Call 仍损失价值。
- 远月 IV 大跌：作为净多 Vega 的结构受损。
- 短 Call 提前指派：账户出现 `-100` 股，需要立即处理，而不是等系统自动修复。

## 2. Diagonal：行权价与到期日都不同

例如买 180 DTE `90 Call @ 14.00`，卖 30 DTE `105 Call @ 1.50`，净借记 `$12.50`。相比同一行权价 Calendar，它带有更明显的正 Delta。

检查最坏的上冲情景：若短 Call 被指派，用长 Call 行权会放弃剩余时间价值；通常应比较：

1. 回购短 Call；
2. 卖出长 Call，再在市场买股完成交割；
3. 滚动短 Call；
4. 只有在时间价值几乎为零且确有必要时才考虑行权长 Call。

## 3. Poor Man's Covered Call（PMCC）

PMCC 用深度价内、较长期 Call 替代 100 股，再持续卖近月 OTM Call。它资本占用较低，但**不是**真正 Covered Call：

- 长 Call 有到期日和 Vega 风险；
- 大跌时长 Call 可能同时损失内在与时间价值；
- 短 Call 指派会产生空股；
- 两个行权价选择不当，股价暴涨时仍可能亏损。

一个保守的结构检查：

\[
\text{短 Call 行权价差} + \text{收到贷记} \ge \text{长 Call 时间价值成本}
\]

这只是结构检查，不是盈利保证。

## 4. 到期管理 SOP

- 短腿剩余 7–10 DTE：重新检查 Gamma、流动性和事件。
- 短腿价内或接近平值：不要让它无计划进入最后一天。
- 平仓时优先整体平 Calendar/Diagonal；若只平短腿，必须重新评估剩余 Long Call 已变成什么观点。
- 滚动必须拆成“平旧仓 + 开新仓”两笔经济决策，并分别记录价格。

## 5. 练习

Calendar 净借记 `$300`，近月到期时长 Call 值 `$4.20`，短 Call 值 `$0.30`。忽略费用，整体平仓盈亏是多少？

??? success "答案"
    平仓净收 `$3.90 × 100 = $390`，减去初始 `$300`，盈利 `$90`。不能只看到短腿赚 `$270` 而忽略长腿的变化。
