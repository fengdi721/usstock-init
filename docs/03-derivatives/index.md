## 阶段检查点

- [ ] 在 IBKR 开通期权交易权限
- [ ] 模拟盘完成每种策略至少一次完整周期
- [ ] 第一笔真实的备兑看涨或现金担保看跌，并写进 [交易日志](../journal/index.md)

!!! danger "最重要的一条"
    在模拟盘上把一种策略完整做过一次之前，不要用真钱交易它。只做**买入**期权或**有正股/现金担保**的卖出期权，绝不裸卖期权。
