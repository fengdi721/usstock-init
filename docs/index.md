# 美股ABC

**从A股老手到美股专业投资者：一位法国居民的 26 周学习路线。**

## 适合谁读

| 项目 | 情况 |
|---|---|
| 居住地 | 法国税务居民（税务、账户部分按法国规则写） |
| 已有账户 | 一个法国 PEA，还没有能买美股的账户 |
| 示例资金 | 文中例子统一按 20,000 欧元计算 |
| 每周学习时间 | 约 6 小时（5 小时主线 + 1 小时英语） |
| 投资风格 | 以长期持有为主，同时系统学习 |
| 衍生品 | 先看懂，之后要能配合正股实际交易期权 |
| A股经验 | 买卖个股，能看基本K线，不会技术分析 |
| 英语 | 读财经英文有些吃力，需要同步提升 |

## 四个阶段

<div class="grid cards" markdown>

- **[阶段一：基础](01-foundations/index.md)**（第 1–4 周）
  美股和A股的区别、市场全景、法国居民的账户与税务，把账户开起来。

- **[阶段二：平台与信息](02-platform/index.md)**（第 5–10 周）
  券商平台、订单类型、换汇成本、读财报、估值、信息源。

- **[阶段三：衍生品](03-derivatives/index.md)**（第 11–20 周）
  ETF、期权、希腊字母、波动率、配合正股的策略、价差、风险。

- **[阶段四：投资体系](04-system/index.md)**（第 21–26 周）
  组合构建、风险管理、交易日志与复盘。

</div>

另外，[财经英语](00-english/index.md) 每周 1 小时，贯穿全程。
