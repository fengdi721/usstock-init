# 交易日志与每周复盘

> **一句话总结**：每周日花 20 分钟写一篇复盘，每笔交易当天写一条记录。半年后，这里会是你最有价值的学习资料。

这个目录存放你自己的记录。文件命名建议：

```
journal/
├── index.md                 本页：使用说明和模板
├── 2026-W46.md              每周复盘（ISO 周编号）
├── 2026-W47.md
├── trades-2026.md           全年交易记录（也可以用电子表格）
└── plan.md                  资金分配计划
```

!!! tip "写完一篇就提交一次"
    ```bash
    git add docs/journal/2026-W46.md
    git commit -m "journal: week 46 review"
    ```
    提交历史就是你的学习进度。新建的复盘文件如果想在网站导航里显示，把它加到 `mkdocs.yml` 的 `nav` 里“交易日志”下面。

更完整的日志方法（季度检讨、规则迭代）见阶段四的 [交易日志与复盘](../04-system/03-journal-template.md)。

复制下面的内容到新文件 `2026-Wxx.md`：

```markdown

- 路线进度：第 x 周，[文档名]
- 完成的练习：

- 英语：新背单词 xx 个，精读材料：

## 2. 市场回顾（3 句话）
- 标普 500：+x.x%，纳斯达克 100：+x.x%
- 本周最重要的事件：
- 我的理解：

## 3. 本周交易
| 日期 | 代码 | 操作 | 数量 | 价格 | 原因 |
|---|---|---|---|---|---|

## 4. 持仓检查
| 代码 | 仓位占比 | 买入理由还成立吗？ | 下一步 |
|---|---|---|---|

## 5. 反思
- 做得好的一件事：
- 想改进的一件事：
- 下周计划：
```

## 模板二：单笔交易记录

每次下单当天记录，**下单前**先写好“理由”和“计划”两栏：

```markdown
### 2026-11-20 买入 MSFT

- **账户**：IBKR CTO
- **操作**：买入 3 股，限价 410 美元，成交 409.80 美元，佣金 1 美元
- **汇率**：EUR/USD 1.08，欧元成本 (3 × 409.80 + 1) ÷ 1.08 = 1,139.26 欧元
- **理由**：云业务增速连续两个季度回升，估值回到 5 年均值附近
- **计划**：长期持有；如果 Azure 增速连续两个季度低于 20%，重新评估
- **仓位**：占总资产 5.7%
- **情绪**：平静 / 兴奋 / 焦虑（如实写）
```

## 示例：第 0 周（起点记录）

> 下面是一个示例，你可以改成自己的版本，保存为 `2026-W45.md`。

**2026 年第 45 周：起点**

1. **我为什么学美股**：（用自己的话写，例如：想系统学习，长期持有，并学会用期权配合正股）
2. **我的资源**：（可投资金额、每周学习时间、已有哪些账户）
3. **资金计划**：（例如 PEA 定投指数 ETF 多少、CTO 买个股多少、留多少做期权学习资金）
4. **我的弱项**：（例如技术分析、财经英语、法国投资税务）
5. **半年后的目标**：
    - [ ] 能独立读懂一份英文财报新闻稿
    - [ ] 能用自己的话解释 Delta 和 Theta
    - [ ] 完成第一笔真实的备兑看涨或现金担保看跌
    - [ ] 第一次独立完成包含 3916 和 2074 的报税
