# 交易日志与复盘：模板、每周市场解读、季度检讨

> **一句话总结**：日志记录“我为什么这么做”，复盘检查“我是否按规则做”，统计告诉你“我的方法到底有没有用”。没有日志的交易，只是在重复同样的错误。

本篇是第 23 周的内容，也是第 24–26 周实战的操作手册。前两篇写好了规则（[组合构建](01-portfolio.md)、[风险管理](02-risk-management.md)），本篇让规则真正被执行和改进。

---

## 和A股对比

| 方面 | 很多人在A股的做法 | 本篇的做法 |
|---|---|---|
| 记录 | 只看账户总盈亏，或者看券商的交割单 | 每笔交易记录**理由、计划、情绪**，不只是价格 |
| 判断对错 | 赚钱 = 对，亏钱 = 错 | 按规则执行 = 好决策，不论盈亏 |
| 复盘 | 大亏之后才想起来复盘 | 每周固定时间、固定模板 |
| 比较对象 | 和群里的朋友比 | 和标普500（欧元计）比 |
| 信息 | 每天刷新闻、看股吧 | 每周一次系统地读市场，平时少看 |
| 税务 | 中国个人买卖A股免资本利得税，不用记成本 | 法国要申报每笔卖出的盈亏（2074 表格），日志同时是报税底稿 |

最后一条很实际：作为法国税务居民，你每年 5 月要申报 CTO 的资本利得。一份好的日志能让报税从“一整个周末的噩梦”变成“半小时的核对”。

## 详细讲解

### 1. 日志记录什么：三层结构

| 层级 | 频率 | 内容 | 花多少时间 |
|---|---|---|---|
| 交易记录 | 每笔交易 | 开仓理由、计划、结果 | 每笔 5 分钟 |
| 每周复盘 + 市场解读 | 每周一次（周末） | 市场发生了什么、我做了什么、是否守规则 | 60–90 分钟 |
| 季度检讨 | 每季度一次 | 统计数据、对比基准、修改规则 | 2 小时 |

### 2. 每笔交易的记录字段

| 字段 | 说明 | 例子 |
|---|---|---|
| 编号 | 方便引用 | 2027-001 |
| 日期 | 开仓 / 平仓日期 | 2027-01-12 |
| 账户 | PEA / CTO | CTO |
| 篮子 | 核心 / 个股 / 主题 / 期权 | 个股 |
| 标的 | 代码 | MSFT |
| 方向和工具 | 买入股票 / 卖出看跌 / 价差…… | 买入股票 |
| 数量和价格 | | 3 股 @ 410 美元 |
| 汇率 | 成交时 EUR/USD | 1.10 |
| **买入理由** | 一到三句话 | “云业务增速连续 4 个季度 >25%，PE 低于 5 年均值” |
| **逻辑止损** | 什么情况说明我错了 | “Azure 增速连续两季度低于 15%” |
| 价格止损 | 如有 | 360 美元 |
| 目标 / 计划 | 持有多久、何时检讨 | 至少持有 2 年，每次财报后检讨 |
| 风险金额 | 止损触发时亏多少欧元 | 136 欧元 |
| 跳空情景 | −30% 时亏多少欧元 | 335 欧元 |
| **情绪** | 下单时的状态 | 平静 / 兴奋 / 害怕 / FOMO（怕错过） |
| 是否符合规则 | 是 / 否，违反哪条 | 是 |
| 平仓价格和日期 | | |
| 盈亏（美元 / 欧元） | 欧元为准 | |
| R 倍数 | 盈亏 ÷ 风险金额 | +1.8R |
| 平仓理由 | 达到逻辑止损 / 价格止损 / 再平衡 / 其他 | |
| 事后评价 | 决策好不好（不是结果好不好） | |

!!! tip "R 倍数（R-Multiple）"
    R = 你在开仓时计划的风险金额。如果计划风险 100 欧元，最后赚了 250 欧元，就是 +2.5R；亏了 100 欧元是 −1R；亏了 180 欧元（比如跳空）是 −1.8R。
    用 R 而不是用金额来衡量，能让不同大小的交易可以互相比较，也能一眼看出“止损有没有被执行”：如果经常出现 −2R、−3R，说明你在扛单。

### 3. 好决策 vs 好结果

这是整个复盘体系的核心思想：

| | **结果好（赚钱）** | **结果差（亏钱）** |
|---|---|---|
| **决策好（守规则、有理由）** | ✅ 应得的回报 | 😐 运气不好，**继续这样做** |
| **决策差（违规、冲动）** | ⚠️ 运气好，**最危险**，会强化坏习惯 | ❌ 应得的惩罚 |

右上和左下最容易被误判。A股里很多人追涨停赚过钱（左下角），于是一直追，直到一次大亏。复盘时，**每笔交易都要先判断在哪个格子里**。

### 4. 统计指标：你的方法到底有没有用

每季度从日志里算出这几个数（满 20 笔以上平仓的交易才有参考意义）：

| 指标 | 公式 | 说明 |
|---|---|---|
| 胜率 | 盈利笔数 ÷ 总笔数 | 单独看没有意义 |
| 平均盈利 | 盈利交易的平均欧元 | |
| 平均亏损 | 亏损交易的平均欧元（取正数） | |
| 盈亏比 | 平均盈利 ÷ 平均亏损 | |
| **期望值** | 见下 | 每笔交易平均赚多少，**最重要** |
| 平均 R | 所有交易 R 的平均 | 与期望值同义，但以风险为单位 |
| 违规率 | 违规笔数 ÷ 总笔数 | 目标 < 10% |

\[
\text{期望值} = \text{胜率} \times \text{平均盈利} - (1 - \text{胜率}) \times \text{平均亏损}
\]

### 5. 和基准比较

卫星部分（个股 + 主题 ETF + 期权）的唯一存在理由，是长期**跑赢**或者至少**不输太多**于把同样的钱放进标普500。

每季度做一次比较：

\[
\text{超额收益} = \text{卫星部分欧元收益率} - \text{标普500 ETF 同期欧元收益率}
\]

用欧元计价的标普500 ETF（例如你 PEA 里的那只）做基准最方便，因为汇率影响已经包含在里面了。

如果连续 4 个季度（1 年）卫星明显跑输基准，并且原因不是“规则内的正常波动”，就应该**认真考虑提高核心比例**。这不是失败，这是数据给你的答案。

### 6. 每周市场解读：固定流程

第 24–26 周开始，每周末做一次市场解读，之后长期保持。建议放在**周六或周日上午**，美股已收盘，信息完整。

**60–90 分钟的流程：**

| 步骤 | 时间 | 看什么 | 去哪里看 |
|---|---|---|---|
| 1. 大盘数字 | 10 分钟 | 标普500、纳斯达克100、罗素2000、欧洲 STOXX 600 本周涨跌；VIX；美国 10 年期国债收益率；EUR/USD | Yahoo Finance、Investing.com、券商行情 |
| 2. 板块 | 5 分钟 | 11 个板块本周谁涨谁跌 | Finviz 板块热力图（Map） |
| 3. 宏观事件 | 15 分钟 | 本周已公布的数据（CPI、非农就业、美联储议息、PMI）和市场反应；下周日历 | 财经日历（Investing.com、TradingEconomics） |
| 4. 持仓与观察列表 | 20 分钟 | 每只持仓本周涨跌和原因；有无财报、新闻；逻辑止损是否被触及 | 券商新闻、公司 IR 网站、SEC EDGAR |
| 5. 英文精读 | 15 分钟 | 选一篇与持仓相关的英文新闻或财报电话会摘要精读 | Reuters、CNBC、公司新闻稿 |
| 6. 写复盘 | 15 分钟 | 按下面的模板写 | 你的日志 |
| 7. 下周计划 | 5 分钟 | 下周有财报的持仓？要做的定投？要检查的规则？ | |

!!! info "为什么一周一次就够了"
    你是长期投资者，不是日内交易者。每天看盘的主要结果是**交易更多、情绪更多**，而不是收益更高。每周一次系统地看，比每天零散地刷新闻有用得多。期权持仓例外：有期权仓位时，工作日每天收盘后花 5 分钟检查一次即可（巴黎时间 22:00 之后，或第二天早上）。

### 7. 你的 6 小时怎么分配（第 24–26 周及以后）

| 活动 | 每周时间 |
|---|---|
| 每周市场解读 + 复盘（含英文精读） | 1.5 小时 |
| 研究一只观察列表里的公司（读财报、写分析） | 2 小时 |
| 期权模拟盘或小额实盘练习 + 记录 | 1 小时 |
| 财经英语（Anki + 听力） | 1 小时 |
| 机动（补学之前不熟的章节） | 0.5 小时 |

### 8. 工具：用什么记日志

| 工具 | 优点 | 缺点 |
|---|---|---|
| 电子表格（Numbers / Excel / Google Sheets） | 能自动算统计、R 倍数、期望值 | 写长文字不方便 |
| Markdown 文件（放在本仓库） | git 管理，能写长文字，能放网站 | 统计要手算或写脚本 |
| **两者结合（推荐）** | 表格记数字，Markdown 写每周复盘 | |

本目录提供了一份表格模板：[journal-template.csv](journal-template.csv)，可以直接用 Numbers 或 Excel 打开。

**IBKR 导出成交记录**：在 IBKR 网页端的 *Performance & Reports → Statements* 里可以生成活动报表（Activity Statement），也可以用 *Flex Queries* 自定义导出 CSV。每月导出一次，和你的日志核对，同时保存好用于第二年 5 月报税。

## 具体例子

### 例子 1：一笔完整的股票交易记录

```markdown
## 2027-003  MSFT  买入股票（CTO / 个股篮子）

- 开仓：2027-01-12，3 股 @ 410.00 美元，佣金 1.00 美元，EUR/USD 1.10
- 成本：1,231.00 美元 ≈ 1,119 欧元（总资金 20,500 欧元的 5.5%）
  - ⚠️ 略超 5% 上限，原因：上周组合下跌导致分母变小。决定：不加仓，下月定投后会回到 5% 以内
- 买入理由：云业务（Azure）增速连续 4 个季度 >25%；公司 AI 产品开始贡献收入；
  前瞻 PE 约 28 倍，低于过去 5 年均值
- 逻辑止损：Azure 增速连续两个季度低于 15%，或管理层下调全年指引
- 价格止损：无（长期仓位），但从买入价下跌 25%（307.50 美元）时强制重写分析
- 风险金额（按 −25% 检讨线计算）：3 × 102.50 = 307.50 美元 ≈ 280 欧元 → R = 280 欧元
- 跳空情景（−30%）：369 美元 ≈ 335 欧元，占总资金 1.6% ✅
- 下次财报：2027-01-28
- 情绪：平静，研究了两周才买
- 是否符合规则：基本符合（仓位略超，已说明）
```

三个月后平仓（假设因为再平衡卖出）：

```markdown
- 平仓：2027-04-15，3 股 @ 455.00 美元，佣金 1.00 美元，EUR/USD 1.08
- 收入：1,364.00 美元 ≈ 1,263 欧元
- 盈亏：1,263 − 1,119 = +144 欧元（其中汇率贡献：美元走强，对你有利）
- R 倍数：144 / 280 = +0.51R
- 平仓理由：再平衡（个股篮子超过目标 5 个百分点）
- 评价：决策好 / 结果好。买入有充分研究，卖出按规则。
- 税务备忘：CTO 盈利 144 欧元，计入 2027 年 2074 表格
```

### 例子 3：季度统计和期望值

假设 2027 年第一季度，你一共平仓了 20 笔卫星交易（股票 + 期权）：

| 项目 | 数值 |
|---|---|
| 盈利笔数 | 9 |
| 亏损笔数 | 11 |
| 胜率 | 45% |
| 平均盈利 | 180 欧元 |
| 平均亏损 | 95 欧元 |
| 盈亏比 | 1.89 |
| 违规笔数 | 3（违规率 15%） |

\[
\text{期望值} = 45\% \times 180 - 55\% \times 95 = 81 - 52.25 = +28.75 \text{ 欧元 / 笔}
\]

胜率不到一半，但期望值是正的，因为赚的时候赚得多、亏的时候亏得少——这正是止损规则的作用。

**再深入一层**：把 3 笔违规交易单独拿出来，发现它们合计亏了 −310 欧元。去掉它们，剩下 17 笔的期望值明显更高。结论：**问题不在方法，在执行**。下季度的改进目标：违规率降到 5% 以下。

| 项目 | 2027 Q1 |
|---|---|

## 常见坑

1. **只记亏损的交易，或者只记赚钱的交易。** 选择性记录让统计完全失真。每一笔都记。
2. **事后补写买入理由。** 理由必须在下单**之前**写，否则你会不自觉地为结果编故事。
3. **用结果评判决策。** 复盘时先看“守没守规则”，再看盈亏。
4. **样本太小就下结论。** 5 笔交易的胜率没有任何意义，至少 20 笔、最好 50 笔以上。
5. **频繁修改规则。** 每季度最多改 2 条，并写清楚原因。每周改规则等于没有规则。
6. **复盘变成“看新闻”。** 每周市场解读的目的是“和我的持仓有什么关系”，不是收集资讯。每条信息都问：这影响我的哪个持仓？需要我做什么吗？大多数时候答案是“不需要”。
7. **忘记汇率。** 日志里每笔都记 EUR/USD，盈亏以欧元为准。
8. **不保存券商报表。** IBKR 的报表要每月下载保存，报税和核对都要用。
9. **复盘坚持了 3 周就放弃。** 把复盘时间固定在日历上，就像上班开会一样。做得简单也比不做好：最差的情况，只填“大盘数字 + 规则检查”两部分也算完成。
